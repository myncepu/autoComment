Privacy Policy – AutoComment Chrome Extension

Last updated: 2026-07-25

This privacy policy explains how the AutoComment Chrome extension ("the extension", "we", "our") handles your data. By installing or using the extension, you agree to this policy.

1. What this extension does

AutoComment helps you quickly post high‑quality promotional comments on websites by:

  • Auto‑filling common form fields (name, email, website, password) using values that you configure in the extension options.
  • Analyzing the current page's content to generate a suggested promotional comment via a third‑party AI API.
  • Optionally inserting the AI‑generated comment into the detected comment textarea.
  • Optionally analyzing outbound links (outlinks) on the current page and showing you a simple report.

2. Data we store locally

The extension uses Chrome's browser storage APIs, including chrome.storage and IndexedDB, to store only the data necessary to provide its features:

  • User profile data you provide (for auto‑fill):
    • Name / username
    • Email address
    • Password (for auto‑filling registration or login forms)
    • Website URL for use in comment forms
  • AI API configuration:
    • Your configured API Base URL and model ID, stored in chrome.storage.sync.
    • Your AI API key, stored only in chrome.storage.local; it is not synced or included in configuration exports.
  • Preference settings:
    • Whether to auto‑open the floating panel on page load
    • Whether to show the optional outbound-link export control
  • Short-term local usage records:
    • Short‑term records about which domains recently had comments generated, to avoid re‑generating content too frequently for the same site.
  • Successful-comment history in IndexedDB:
    • Successful-comment history is written to IndexedDB on this device first. It leaves the device only if you choose to enable optional cloud synchronization.
    • It preserves the exact submitted comment HTML (the editor value), plus a whitespace-normalized plain-text representation derived from that HTML, target page URL and domain, promoted website URL and domain, submission time and status, batch/task identifiers, source, and each anchor's whitespace-normalized text and raw/resolved URL.
    • This history does not separately capture names, email addresses, passwords, API keys, or other form credentials.

Local data is stored on your device using Chrome's storage APIs. It is not sold or shared with advertisers.

3. Optional cloud synchronization

Cloud synchronization is optional and off until you enable it. When enabled, the extension sends successful-comment history and only the following allowlisted, non-sensitive settings to the AutoComment Cloudflare Worker for storage in Cloudflare D1: promotion URL and content, auto-fill name and email, AI API Base URL and model ID, whether to show the outbound-link export control, batch checkbox settings, batch concurrency, batch timeout, and the public comment user ID.

The synchronized comment record contains the exact history fields listed above. Your form password and AI API key remain only in this browser's local storage and are not uploaded to Cloudflare D1. Cookies, page credentials, temporary batch URL queues, submit contexts, and recovery checkpoints are also excluded from cloud synchronization.

A sync key connects browsers to the same cloud vault. Anyone you share the sync key with can access, change, and delete the synchronized vault, so keep it private. If you lose the sync key, it cannot be recovered and the vault cannot be reconnected from a new browser. AutoComment does not currently provide sync-key rotation.

Cloud history is retained until you permanently delete individual records from all devices or delete the cloud vault. The 90-day local cache eviction applies only after the cloud has confirmed the exact synchronized revision; records that are not cloud-confirmed are not automatically evicted. When cloud synchronization is disabled, the existing export reminder and explicit local deletion flow remains in effect.

Uninstalling the extension from one device deletes that device's local extension data, but does not delete the cloud vault or its copies available to other connected devices. Delete the cloud vault explicitly before uninstalling if you want its synchronized data removed.

4. Data we read from the page

To work, the extension needs to read some information from the page you are viewing:

  • Form fields on the current page (input and textarea elements) to:
    • Detect registration / comment / feedback forms.
    • Fill fields such as name, email, website URL, and password with the values you have configured.
    • Insert the AI‑generated comment into a suitable textarea when you request it.
  • Basic page content to generate a relevant comment:
    • Page URL
    • Page title
    • Meta description (if present)
    • A truncated snippet of visible text from the page body (with length limits and basic cleaning)
  • Links on the current page (for the optional outlink analysis feature):
    • Anchor URLs and hostnames
    • Whether links are dofollow / nofollow based on their rel attributes

The extension does not read your full browsing history and does not track you across websites. Static content scripts match <all_urls> and run on matching pages after they load, including tabs opened for batch processing.

5. Data sent to third‑party services (AI API)

Only when you request a promotional comment, the extension sends a minimal summary of the current page directly to the OpenAI-compatible API provider you configured:

  • Current page URL
  • Page title
  • Meta description (if present)
  • A truncated, cleaned snippet of visible page text
  • The AI prompt / skill template text used to instruct the model

The remote service returns a plain‑text comment suggestion. The extension does not execute arbitrary remote code; it only uses the remote API to generate text.

The API key is sent as authorization only to your configured provider when you generate text or actively test the connection; only generation sends the limited page context listed above.

Please refer to the AI API provider's own privacy policy to understand how they handle data sent to their service.

6. What we do not do

  • We do not sell your data.
  • We do not use your data for targeted advertising.
  • We do not build cross‑site browsing profiles.
  • We do not execute arbitrary remote code.
  • We do not override or modify third‑party scripts on visited pages.

7. Permissions explained

  • activeTab: Available for user-initiated tab interactions; it does not grant or describe the static content scripts' page access.
  • Content-script matches: Static content scripts use <all_urls> to run on matching loaded pages, including user-initiated batch tabs, where they read the page data and fill recognized form fields described above.
  • Model API host permissions: OpenRouter has default model API host permission; saving or testing another HTTP(S) API Base URL requests optional permission only for that provider host.
  • storage: Used to store your profile data, API Base URL, model ID, locally stored API key and sync key, preferences, and cooldown records as described above.
  • unlimitedStorage: This permission prevents the normal extension storage quota from blocking local comment history as it grows.
  • alarms: This permission schedules cloud synchronization, local retention checks, and history reminders. Automatic local cache eviction remains subject to the cloud-confirmation guard described above.
  • notifications: This permission shows local reminders when history approaches or passes the 90-day cleanup threshold.

8. Data retention

Profile data, API configuration, preferences, and cooldown records are kept on your device until you change or clear them, reset the extension, or uninstall it.

Short‑term "cooldown" records used to avoid regenerating content for the same domain are automatically cleaned after a limited time window.

With cloud synchronization disabled, history becomes eligible for cleanup after 90 days on a rolling basis, but the reminder alarm never deletes it. Deletion is available only after export and your explicit confirmation; canceling leaves the records untouched.

With cloud synchronization enabled, cloud-confirmed local cache entries may be evicted as described above, while the cloud copy remains until explicit deletion. Uninstall behavior is described in the optional cloud synchronization section.

9. Security

We rely on Chrome's extension security model, chrome.storage for settings, and IndexedDB for comment history. However, no method of storage or transmission is 100% secure. You should not store highly sensitive passwords or confidential information in the extension if you are uncomfortable doing so.

10. Children's privacy

This extension is intended for use by adults. It is not directed to children and does not knowingly collect personal information from children.

11. Your choices

  • You can disable or remove the extension at any time in your browser's extension settings.
  • You can clear or change the data stored by the extension (such as your profile, API key, or preferences) at any time via the extension's options page.
  • You may choose not to enter an AI API key; in that case, the AI comment generation feature will be disabled.

12. Changes to this policy

We may update this privacy policy from time to time. The "Last updated" date at the top indicates the latest revision. Your continued use of the extension after any changes signifies your acceptance of the updated policy.

13. Contact

隐私政策 – AutoComment Chrome 扩展（简体中文摘要）

以下中文内容为简要说明，如与英文版本存在差异，以英文版本为准。

一、扩展的主要功能

AutoComment 帮助你在各类网站上快速发布高质量推广评论，包括：

  • 根据你在扩展选项中配置的姓名、邮箱、网站等信息自动填写表单。
  • 基于当前网页内容，通过第三方 AI 接口生成英文推广评论文案。
  • 在识别到的评论框中自动填入或聚焦该文案。
  • 可选：对当前页面的外链（outlinks）做简单分析并展示报告。

二、本地存储的数据

扩展只会在本地通过 Chrome 浏览器存储 API（包括 chrome.storage 和 IndexedDB）存储实现功能所必需的数据：

  • 你在扩展中手动填写的资料：姓名/昵称、邮箱、密码、网站 URL。
  • API Base URL 和模型 ID（保存在 chrome.storage.sync）。
  • 用于调用 AI 的 API Key（仅保存在 chrome.storage.local，不会同步或导出）。
  • 开关类偏好设置：是否自动打开浮窗、是否显示可选的外链导出控件等。
  • 用于避免在同一域名过于频繁生成文案的短期本地冷却记录（会定期清理）。
  • 成功评论历史会先写入本设备的 IndexedDB；只有当你主动启用可选的云同步时，它才会离开本设备。它会精确保留实际提交的评论 HTML（即编辑器值），并保存从该 HTML 派生且经过空白规范化的纯文本表示、目标页面 URL 和域名、推广网站 URL 和域名、提交时间与状态、批次/任务标识、来源，以及每个链接经空白规范化的锚文本和原始/解析后 URL。该历史不会另行收集姓名、邮箱地址、密码、API Key 或其他表单凭据。

本地数据通过 Chrome 浏览器存储 API 保存在你的设备上，不会出售，不用于投放广告。

三、可选的云同步

云同步是可选功能，只有你主动启用后才会运行。启用后，扩展会把成功评论历史以及以下白名单内的非敏感设置发送到 AutoComment Cloudflare Worker，并存储在 Cloudflare D1：推广 URL 与文案、自动填表的姓名与邮箱、AI API Base URL 与模型 ID、是否显示外链导出控件、批处理复选框设置、批处理并发数、批处理超时时间，以及公开的评论用户 ID。

同步的评论记录包含上文列出的精确历史字段。你的表单密码和 AI API Key 只保存在当前浏览器本地，不会上传到 Cloudflare D1。Cookie、页面凭据、临时批量 URL 队列、提交上下文和恢复检查点也不会参与云同步。

同步密钥用于让不同浏览器连接同一个云端仓库。任何获得同步密钥的人都能访问、修改和删除该同步仓库中的数据，因此请妥善保管。同步密钥丢失后无法恢复，也无法重新连接该云端仓库；AutoComment 目前不支持轮换同步密钥。

云端历史会一直保留，直到你从所有设备永久删除单条记录，或删除整个云端仓库。本地超过 90 天的缓存记录，只有在云端已确认完全相同的同步版本后才可能自动清理；未经云端确认的记录不会被自动清理。关闭云同步时，原有的导出提醒和明确确认后本地删除流程保持不变。

从一台设备卸载扩展会删除该设备上的本地扩展数据，但不会删除云端仓库，也不会删除其他已连接设备可访问的副本。如果希望移除同步数据，请在卸载前明确删除云端仓库。

四、从网页读取的数据

为实现自动填表、识别评论框和生成文案，扩展会在当前页面读取：

  • 表单字段（input/textarea）信息，用于识别并填写姓名、邮箱、网站、密码等。
  • 页面基础信息：URL、标题、描述标签（如有）、以及经过截断和清洗的一小部分正文文本。
  • 外链分析功能下：页面中的链接 URL、域名以及是否带有 nofollow 属性。

扩展不会读取你的全局浏览历史，也不会跨站跟踪你。静态内容脚本通过 <all_urls> 在匹配的已加载页面运行，包括用户发起的批量处理标签页。

五、发送到第三方 AI 服务的数据

仅当你主动请求生成推广文案时，扩展才会将当前页面的精简摘要（URL、标题、描述、截断后的正文内容）以及提示词模板直接发送给你配置的 OpenAI 兼容 API 服务商，以便生成一段评论文案。

API 返回的仅是纯文本文案。扩展不会执行远程代码，也不会下载远程脚本。

API Key 只会在你请求生成文案或主动测试连接时作为授权信息发送给你配置的服务商；只有生成请求会发送上述有限的页面上下文。

六、我们不会做的事情

  • 不会出售你的数据。
  • 不会用你的数据做定向广告或跨站画像。
  • 不会执行任意远程代码。
  • 不会篡改第三方网站的脚本逻辑。

七、权限说明

  • activeTab：可用于用户发起的标签页交互；它不授予也不描述静态内容脚本对页面 DOM 的访问。
  • 内容脚本匹配范围：静态内容脚本通过 <all_urls> 在匹配的已加载页面运行，包括用户发起的批量处理标签页；它们会读取上述页面数据并填写识别到的表单字段。
  • 模型 API 主机权限：OpenRouter 默认拥有模型 API 主机权限；保存或测试其他 HTTP(S) API Base URL 时，只会为该服务商主机请求可选权限。
  • storage：用于保存上述资料、API Base URL、模型 ID、仅本地保存的 API Key 与同步密钥、偏好设置和冷却记录。
  • unlimitedStorage：此权限用于避免常规扩展存储配额阻碍本地评论历史持续增长。
  • alarms：此权限用于安排云同步、本地保留期限检查和历史提醒。自动清理本地缓存仍受上文云端确认条件约束。
  • notifications：此权限用于在历史记录接近或超过 90 天清理阈值时显示本地提醒。

八、你的选择

关闭云同步时，历史记录按滚动周期在满 90 天后才具备清理资格，但提醒闹钟绝不会删除记录。只有先导出并由你明确确认后才会删除；取消操作会保留全部记录。启用云同步时，只有符合上文云端确认条件的本地缓存才会自动清理，云端副本仍会保留到你明确删除为止。

  • 你可以随时在浏览器中禁用或卸载本扩展。
  • 你可以在扩展选项页中随时修改或清空存储的数据。
  • 如果你不填写 API Key，则不会调用 AI，文案生成功能将保持关闭。
